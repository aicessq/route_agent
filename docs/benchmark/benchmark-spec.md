# BenchmarkSpec（预注册基准规范）

> 状态：**预注册，待阶段 2/4 实测**。本文在优化前冻结实验参数；
> 所有目标值为设计门槛（非实测结果），实测数字只允许填入 `eval/results` 与报告中。

## 1. 环境声明（实测时必须完整记录）

- 机器：本机（CPU/内存/OS 写明）
- Python 版本、依赖锁定（pip freeze 快照入仓）
- 数据规模：10 万级路线索引（真实种子 + 合成扩增，生成器版本入仓）
- 并发模型：asyncio Worker × N 实例

## 2. 负载模型（分层工作负载）

| 负载 | 目的 |
| --- | --- |
| 热点查询集（高复用地点/条件） | 缓存命中率、singleflight 合并 |
| 长尾查询集（冷缓存地点） | 回源成本、击穿保护 |
| 混合复杂约束集 | 真实漏斗深度 |
| 突发流量（N→100 瞬时） | 背压、快速拒绝、普通搜索隔离 |
| 慢 Provider（注入延迟） | 超时、熔断、部分降级 |

冷/热缓存**分别**报告。

## 3. 并发阶梯

`1 / 10 / 25 / 50 / 100` 并发 Run；任务创建与轮询接口另行更高并发压测。
超配额时验收"排队 + 快速拒绝 + retryAfter"，不要求全部同时执行。

## 4. 消融实验（逐项归因）

| 档位 | 配置 |
| --- | --- |
| A0 | 逐候选单查（N+1 基线） |
| A1 | 统一批量 Evidence 接口 |
| A2 | A1 + 两级缓存 + singleflight |
| A3 | A2 + Top-K 漏斗 + 早停 |

固定数据/机器/负载，逐项比较调用量、吞吐、P95/P99、单 Run 成本。

## 5. 指标（完整四类）

1. **API**：创建接口 QPS / P50 / P95 / P99 / 错误率；轮询 QPS。
2. **端到端**：入队→报告的延迟分布、队列等待、完成率。
3. **检索效率**：候选漏斗各层规模、Provider 调用数、批量大小、缓存命中率、
   singleflight 合并数、早停比例。
4. **资源与成本**：token/费用（价格版本化）、Worker CPU/内存、MySQL/Redis 压力、过载拒绝率、
   单 Run CostReport。

## 6. 质量门禁（性能优化的守门指标）

以无漏斗/大 K 的离线结果为近似上界：

- **硬约束误通过率 = 0**（绝对门槛）。
- 符合路线发现率（candidate recall）不低于冻结阈值。
- 引用支持率不下降。
- UNKNOWN 占比增幅在阈值内。

阈值在 Golden Set 基线跑出后冻结；性能收益不得用漏召回换取。

## 7. 延迟门槛（设计目标，非实测）

| 项 | 目标 |
| --- | --- |
| 创建接口 P95 | < 200ms |
| 正常决策 P95 | 20–30s |
| 硬截止 | 60s（截止后输出当前已验证结果或 INSUFFICIENT_EVIDENCE） |

## 8. 可靠性验收（七类故障注入，阶段 3）

| 故障 | 不变量 |
| --- | --- |
| DB 提交后入队前崩溃 | 状态不丢、不双写 |
| 工具发出后落库前强杀 | 有界重试、去重、无重复费用 |
| 租约过期接管 | 单一执行者 |
| Redis 清空 | 从 MySQL 恢复调度 |
| 主备 LLM 均不可用 | 已编译任务继续、模板输出 |
| 关键/非关键工具超时 | 硬约束 UNKNOWN 不得 PASS |
| 取消后的迟到结果 | 不推进已取消 Run |
